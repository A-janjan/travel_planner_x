# Contributing

Thanks for considering a contribution.

1. Create a branch for your change and keep pull requests focused.
2. Do not commit `.env` files, API credentials, generated caches, or personal travel data.
3. Add or update tests and relevant documentation.
4. Run `pytest`, `python -m compileall -q agents services workflows main.py utils.py`, and `ruff check .` before opening a pull request.
5. Include a concise description of user-visible behavior and any changes to external providers or configuration.

Please confirm data and asset licensing before adding third-party content.
