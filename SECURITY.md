# Security policy

This project is a prototype and does not yet provide authentication or production-grade session protection. Do not deploy it with sensitive or private trip data until the recommendations in [the security guide](docs/security.md) are addressed.

If you find a security issue, avoid opening a public issue with credentials, personal information, or an exploit that affects a live service. Contact the repository maintainer privately once repository contact details are configured.

If a credential was exposed in any revision, remove it from the active code and rotate it with its provider; deleting it from the latest file is not sufficient to remove it from Git history.
